Design Tokens

Colors

Reusable color variables for backgrounds, text, accents, borders, and palette values.

--bg-primary --text-primary --accent-primary

Typography

Font families, sizes, and weights used to keep text styling consistent.

--font-primary --fs-md --fw-bold

Spacing

Consistent spacing scale for padding, margins, gaps, and layouts.

--space-xs --space-sm --space-lg

Radius & Shadows

Reusable border radius and shadow values for cards, buttons, and surfaces.

--radius-md --shadow-md --shadow-lg

Components

Design Section

A reusable layout wrapper used for each major part of the style guide.

.design-section

Design Card

A reusable card component for colors, typography samples, tokens, and examples.

.design-card

Button System

A shared button base class with reusable visual variants.

.button .button-primary .button-outline

Theme Toggle

A small interactive control that switches between light and dark mode.

.theme-toggle

Accessibility

Semantic HTML

The project uses semantic elements such as <header>, <nav>, <main>, <section>, and <footer> to improve structure and screen reader support.

Keyboard Navigation

Interactive elements such as navigation links and theme toggle buttons are fully keyboard accessible and preserve visible focus states.

Color Contrast

The color palette was designed to maintain readable contrast ratios across both light and dark themes.

Responsive Design

Flexible layouts, responsive grids, and scalable spacing tokens ensure the interface remains usable across multiple screen sizes.

Theme System

Light & Dark Mode

The interface supports dynamic light and dark themes using CSS custom properties and data attributes.

[data-theme="light"] [data-theme="dark"]

Persistent Preferences

The selected theme is stored using localStorage so the user's preference remains active after refreshing the page.

localStorage.setItem()

Reusable Tokens

Backgrounds, text colors, borders, and surfaces automatically adapt through reusable design tokens.

--bg-primary --text-primary

Interactive Toggle

A reusable theme toggle button dynamically updates the interface and switches icons using Lucide icons.

.theme-toggle
